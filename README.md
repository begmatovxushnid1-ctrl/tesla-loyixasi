# Tesla Rasmiy Sayti Klon Loyihasi (Next.js + TypeScript + Tailwind CSS)

Ushbu loyiha **Next.js (App Router)**, **TypeScript** va **Tailwind CSS** yordamida yaratilgan interaktiv **Tesla** veb-sayti klonidir.

## Asosiy imkoniyatlar

- **Ikki tilli interfeys (UZ / EN)**: Yuqori menyudagi tugma orqali O'zbek va Ingliz tillariga bir zumda o'tish.
- **Full-Screen Scroll-Snap Bosh sahifa**:
  - **Model Y**, **Model 3**, **Model X**, **Model S** va **Cybertruck** bo'limlari
  - Har bir bo'limda tezkor rang almashtirib ko'rish (Paint Preview), asosiy texnik ko'rsatkichlar (WLTP masofa, 0–100 km/s, maksimal tezlik va ot kuchi)
  - **Quyosh Panellari va Powerwall 3** bo'limi + interaktiv quyosh quvvati va batareya kalkulyatori
  - **Tesla Aksessuarlari va Wall Connector** bo'limi
- **Mega-Menu Navbar**: Avtomobillar, Energiya va Quvvatlash bo'limlari ustiga borganda ochiladigan interaktiv menyu.
- **Avtomobil Konfiguratori (`/configure`)**:
  - Barcha 5 ta modelni (Model Y, 3, X, S, Cybertruck) tanlash
  - **5 xil ko'rish burchagi**: Old ko'rinish, Yon profil, Orqa ko'rinish, **Salon va 15.4" Ekran**, hamda **3D Avtopilot (FSD Neural Net) ko'rinishi**
  - Komplektatsiya (RWD, Long Range AWD, Performance / Plaid / Cyberbeast)
  - Tashqi bo'yoq ranglari, disklar (masofaga ta'siri bilan), salon rangi, Avtopilot paketlari va quvvatlagichlar
  - **Naqd / Lizing / Kredit** kalkulyatori va buyurtmani rasmiylashtirish oynasi
- **Test Drayvga yozilish va Modellarni solishtirish** modal oynalari.

## Ishga tushirish

```bash
npm.cmd install
npm.cmd run dev
```

Brauzerda `http://localhost:3000` manzilini oching.
